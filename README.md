## 🚀 Getting Started

Clone the repository:

```bash
git clone git@github.com:jacobrees/Guitar-Fretboard-Generator.git
```

Navigate into the project:

```bash
cd Guitar-Fretboard-Generator
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
